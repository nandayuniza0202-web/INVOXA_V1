INVOXA CLEAN

Cara menjalankan:

1. Buka Terminal.
2. Masuk ke folder proyek:
   cd "/Users/nandayuniza/Desktop/invoxa_clean"
3. Buat virtual environment:
   python3 -m venv .venv
4. Aktifkan:
   source .venv/bin/activate
5. Install:
   pip install -r requirements.txt
6. Jalankan:
   streamlit run app.py

Tidak membutuhkan OpenAI API key.
